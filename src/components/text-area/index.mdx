# Text Area

The **Text Area** component provides a multi-line input field for users to enter larger amounts of text.  
It features built-in character counting, validation states, and a modern UI that matches the Polapedia design system.

## Sizes

TextArea supports three height sizes:

- **sm** — 120px height
- **md** — 150px height (default)
- **lg** — 200px height

## Validation States

Semantic feedback is provided through states:

- **default** — Neutral appearance.
- **error** — Red border and label, automatically includes an alert icon. Triggered by `state="error"` or when exceeding `maxLength`.
- **success** — Green border and label, automatically includes a success icon.

<Canvas of={TextAreaStories.States} />

---

## Character Limit

The component includes a live character counter. When `maxLength` is reached:

- The counter and border turn red.
- The `helperText` is replaced by a "Character limit exceeded" message.
- The state effectively becomes `error`.

## Usage Guidelines

- Use **TextArea** for inputs like descriptions, reviews, or comments.
- Always provide a `label` for clarity.
- Use `helperText` for instructions or validation messages.
- Set a reasonable `maxLength` to guide user input.
- Reserve `rightIcon` for non-semantic indicators.

---

## Accessibility

- Built using semantic `<textarea>` and `<label>` elements.
- Accessible focus states for keyboard navigation.
- Color contrast follows accessibility standards.
- Error messages are clearly associated with the input field.
