# Checkbox

The **Checkbox** component lets users make binary choices
and is primarily intended for **multiple selection**, while still supporting single-select usage.
It supports four sizes, two color variants, validation states, indeterminate state,
helper messages, disabled and required states.

## Sizes

Checkbox supports four control sizes that scale both the box and the label:

- **sm** — compact checkbox with smaller label text
- **md** — default checkbox and label size
- **lg** — larger checkbox for comfortable touch targets
- **xl** — extra large, suited for prominent single-choice scenarios

## Interaction & Behavior

- The Checkbox toggles its value using the standard `onChange` event.
- **State Management**:
  - **Controlled** — pass a `checked` prop and handle `onChange`.
  - **Uncontrolled** — omit `checked`; the browser manages its own state.
- **Interactive Layers**:
  - **Normal**: Uses gradient (Primary) or solid color (Secondary).
  - **Hover**: Shifts to a slightly darker shade (`primary-700`) to indicate interactivity.
  - **Pressed/Active**: Dims further (`primary-800`) to provide tactile feedback.
- **Indeterminate State**: Must be used as a prop — the component sets it on the DOM node internally via `useEffect`.
- **Focus States**: A focus ring appears with a small offset to ensure clear visibility during keyboard navigation.
  - Defaults to a **primary-700** ring.
  - Switches to a **red** ring when `state="error"`.

## Usage Guidelines

- Use **Checkbox** for binary decisions where users can select **zero, one, or many** options.
- Use `variant="primary"` (default) for primary actions; `variant="secondary"` for secondary or softer contexts.
- Use the `indeterminate` prop on a parent checkbox when a group has **mixed** selection.
- Use `state="error"` when validation fails (e.g., "You must accept the terms").
- Prefer concise labels and descriptive helper text.

---

## Accessibility

- **Semantic Input**: Uses a native `<input type="checkbox" />` for robust screen reader and keyboard support.
- **Semantic Linking**: Uses `aria-describedby` to programmatically link the checkbox with its `helperText`.
- **Validation State**: Automatically sets `aria-invalid` when `state="error"` to communicate issues to assistive technologies.
- **Mixed States**: The `indeterminate` state is handled via the native DOM property, ensuring screen readers announce it as "mixed".
- **Keyboard Navigation**:
  - Use **Tab** to focus.
  - Use **Space** to toggle the checked state.
- **Visual Focus**: Focus rings are only visible during keyboard interaction (`focus-visible`).
