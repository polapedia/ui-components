# Breadcrumb

A navigation component that helps users understand their current location within the site hierarchy and navigate back to parent pages.

## Props

<ArgTypes of={BreadcrumbStories} />

### Key props

- `items: BreadcrumbItem[]` **(required)**  
  Array of breadcrumb items. Each item has a `label` (string) and an optional `href` (string). The last item is always treated as the current page and rendered without a link.

- `size?: "sm" | "md" | "lg"`  
  Controls font size and separator icon size.  
  Default: `"md"`.

- `separator?: ReactNode`  
  Custom separator element rendered between items.  
  Default: `<ChevronRightIcon />`.

- `className?: string`  
  Extends the root `<nav>` with custom Tailwind classes.

## Usage guidelines

### When to use

- Use **Breadcrumb** on pages that are nested more than one level deep.
- Always include a link back to **Home** as the first item.
- The **last item** should never have an `href` — it represents the current page.

### Accessibility notes

- The root element is a `<nav>` with `aria-label="Breadcrumb"` for screen reader context.
- The current page item has `aria-current="page"`.
- Separator icons are wrapped with `aria-hidden="true"` so screen readers skip them.
- Links are native `<a>` tags, ensuring full keyboard navigability.

## Usage examples

### Basic usage

```tsx
import Breadcrumb from '@/components/breadcrumb';

<Breadcrumb
  items={[
    { label: 'Home', href: '/' },
    { label: 'Marketplace', href: '/marketplace' },
    { label: 'Desain Rumah' },
  ]}
/>;
```

### With custom separator

```tsx
import Breadcrumb from '@/components/breadcrumb';

<Breadcrumb
  size="sm"
  separator="/"
  items={[
    { label: 'Home', href: '/' },
    { label: 'Category', href: '/category' },
    { label: 'Current Page' },
  ]}
/>;
```
