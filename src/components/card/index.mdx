# Card

A flexible container component used to group related content and actions.

The Card component supports four distinct visual styles:

- **Product Variant**: Ideal for displaying items with images, ratings, and rich details (e.g., e-commerce grid, property listings).
- **Simple Variant**: Designed for highlighting text-heavy content, features, or categories with a gradient background.
- **Review Variant**: Suited for standard user testimonials and reviews.
- **Marketplace Review Variant**: Comprehensive layout for detailed marketplace reviews including author info, product details, and seller response.

It is fully responsive, adjusting layout and typography across mobile, tablet, and desktop breakpoints.

## Variants

### Product Card

The default variant designed for rich media content. It features a white background, drop shadow, and dedicated slots for images and ratings.

<Canvas of={CardStories.ProductDefault} />

Use this variant for:

- E-commerce product listings.
- Real estate properties.
- Blog post previews with thumbnails.

---

### Product Marketplace Card

A specialized layout for the product variant (`layout="marketplace"`) designed for e-commerce and marketplace listings. It features a prominent wishlist button, top badge, verified icon, and location details.

<Canvas of={CardStories.ProductMarketplace} />

Use this variant for:

- Marketplace listings and search results.
- Product catalog grids requiring location and verified seller information.

---

### Simple Card

A sleek variant featuring a gradient background (`from-gradient-primary` to `to-gradient-secondary`) with white text. It focuses on the title and description, omitting the main image and rating slots.

<Canvas of={CardStories.SimpleDefault} />

**Note on Flexibility:**
This variant is designed to be highly flexible. We have removed the fixed `min-height` and switched to symmetric vertical padding. You can easily override the vertical padding from the outside by passing Tailwind classes through the `className` prop (e.g., `className="py-10"`).

Use this variant for:

- Key features or unique selling points (USPs).
- Categories or navigation cards.
- Testimonials without user avatars.

## Props

<ArgTypes of={CardStories} />

### Key props

- `variant?: "product" | "simple" | "review" | "marketplace-review"`  
  Determines the visual style and layout of the card.  
  Default: `"product"`.

- `title: string` **(required)**  
  The main heading text of the card.

- `imageSrc?: string`  
  URL for the main image. Applies to the product variant only.

- `rating?: number`  
  Star rating value between 0 and 5. Applies to the product and review variants.

- `buttonText?: string`  
  Label for the call-to-action button. Applies to the product variant only.  
  Default: `"View Product"`.

- `onButtonClick?: () => void`  
  Callback fired when the call-to-action button is clicked.

- `imageHeightClassName?: string`  
  Custom Tailwind class to control image height.  
  Default: `"h-[250px]"`.

- `className?: string`  
  Extends the root container with custom Tailwind classes.

## Usage guidelines

### When to use

- Use **Card** to group information that belongs to a single subject.
- Use **Product Variant** when the visual (image) is as important as the text.
- Use **Simple Variant** to create visual breaks or highlight specific information blocks in a landing page.
- Use **Review Variant** to showcase user testimonials.
- Use **Marketplace Review Variant** to provide in-depth product feedback with product context.

### Visual & layout

- **Responsiveness**: The component handles padding and font-size scaling automatically across mobile, tablet, and desktop breakpoints.
- **Images**: Ensure `imageSrc` images have a consistent aspect ratio for the best grid alignment. `object-cover` is applied by default.
- **Icons**: `topIcon` is positioned differently depending on the variant — top-left for Product, absolute top overlay for Simple.

### Accessibility notes

- Ensure `buttonText` is descriptive (e.g., `"View Property"` instead of `"View"`).
- The card root is a `div`. If the entire card should be clickable, wrap it in a `Link` or apply an `onClick` handler on the root carefully.

## Usage examples

### Product Card

```tsx
import Card from '@/components/card';
import { HomeIcon, PlusOneIcon } from '@/icons';

<Card
  variant="product"
  title="Luxury Villa"
  subtitle="South Jakarta"
  description="A beautiful villa with a private pool and garden."
  imageSrc="/images/villa.jpg"
  rating={4.8}
  topIcon={<HomeIcon />}
  rightIcon={<PlusOneIcon />}
  buttonText="View Details"
  onButtonClick={() => router.push('/villa/123')}
/>;
```

### Product Marketplace Card

```tsx
import Card from '@/components/card';

<Card
  variant="product"
  layout="marketplace"
  title="Batik Tulis Jogja"
  subtitle="Toko Batik Nusantara"
  imageSrc="/images/batik.jpg"
  price="150000"
  rating={4.5}
  metaText="120 terjual"
  locationName="Yogyakarta"
  isVerified
  topBadge="Terlaris"
  onProductClick={() => router.push('/product/batik-tulis')}
  onWishlistClick={() => toggleWishlist('batik-tulis')}
  onActionClick={() => addToCart('batik-tulis')}
/>;
```

/>;
