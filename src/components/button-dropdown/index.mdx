# Button Dropdown

Button Dropdown displays a list of additional related options or actions when triggered.
It combines a standard button style with a toggleable overlay, supporting both structured menu items and custom content.

## Usage Guidelines

- **Items vs Children:** Prefer using the `items` prop for standard selection menus. Use `children` only when you need custom layouts (e.g., forms, complex information).
- **Labeling:** Use `updateLabelOnSelect` to automatically show the selected item's label on the trigger button.
- **Accessibility:** Ensure that icons used in menu items have appropriate alternative text if they convey meaning.
