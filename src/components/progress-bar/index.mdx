# Progress Bar

Progress Bar is a visual indicator of a task's progress or a specific value within a known range.
It provides feedback to the user about the status of an ongoing process.

## Sizes

The Progress Bar supports three vertical sizes:

- **sm** - 16px height
- **md** - 18px height (default)
- **lg** - 20px height

## Usage Guidelines

- **Real-time Feedback**: Use the Progress Bar to provide feedback for actions that take time to complete, like file uploads or data processing.
- **Clear Range**: Ensure the `max` value is clearly defined so the progress is meaningful to the user.
- **Accessibility**: Use appropriate labels or text alongside the progress bar to communicate the status to screen reader users.
