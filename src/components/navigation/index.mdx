# Navigation

Global navigation component for Polapedia. Supports two variants selected via the `variant` prop.

**Variant: `default`**

- Use case: Landing page / company profile
- Contents: Logo · nav links · Contact button

**Variant: `marketplace`**

- Use case: Marketplace app
- Contents: Sidebar · logo · icons · search bar · creator link

### Visual variants

`visualVariant` controls the container style.

- **`elevated`** (default) — Drop shadow + subtle border. Best for colored or textured backgrounds.
- **`flat`** — Border only, no shadow. Best for clean white backgrounds.

> Regardless of `visualVariant`, scrolling past 20 px always activates the elevated shadow automatically.

### Usage

```tsx
import Navigation, { type NavItem } from '@/components/ds/navigation';

const items: NavItem[] = [
  { label: 'Home', href: '/' },
  { label: 'About Us', href: '/about-us' },
  { label: 'Polo AI', href: '/polo-ai' },
  { label: 'Marketplace', href: '/marketplace' },
  { label: 'Terms Of Service', href: '/tos' },
];

export default function LandingPage() {
  return (
    <Navigation
      items={items}
      activeHref="/"
      contactLabel="Contact"
      onContactClick={() => router.push('/contact')}
    />
  );
}
```

### Search bar

Supports **uncontrolled** (default) and **controlled** modes.

**Uncontrolled** — component manages its own input state. Use `onSearchSubmit` to react when the user presses Enter.

```tsx
<Navigation
  variant="marketplace"
  onSearchSubmit={(q) => router.push(`/search?q=${encodeURIComponent(q)}`)}
/>
```

**Controlled** — pass `searchQuery` + `onSearchChange` to drive the value from the parent. Useful for debouncing or syncing state elsewhere.

<Canvas of={NavigationStories.MarketplaceControlledSearch} />

**Dropdown** — pass `searchDropdown` to render custom search suggestions inside the search container. Use `onSearchFocus` and `onSearchClickOutside` to control visibility from the parent.

<Canvas of={NavigationStories.MarketplaceSearchDropdown} />

### Category dropdown

The category label exposes `onCategoryMouseEnter` and `onCategoryMouseLeave`. Render custom dropdown content via `children` so it stays positioned below the marketplace header.

<Canvas of={NavigationStories.MarketplaceCategoryDropdown} />

```tsx
export default function MarketplaceLayout({ children }) {
  const [isCategoryOpen, setIsCategoryOpen] = useState(false);

  return (
    <>
      <Navigation
        variant="marketplace"
        onCategoryMouseEnter={() => setIsCategoryOpen(true)}
        onCategoryMouseLeave={() => setIsCategoryOpen(false)}
      >
        {isCategoryOpen && <CategoryDropdown />}
      </Navigation>
      {children}
    </>
  );
}
```

## Accessibility

- Semantic `<nav>` and `<a>` elements throughout.
- Active link carries `aria-current="page"`.
- Disabled links are removed from the tab order via `tabIndex={-1}`.
- Hamburger button uses `aria-label` and `aria-expanded`.
- Icon buttons in the marketplace variant carry descriptive `aria-label` attributes.
- All interactive elements have visible focus outlines for keyboard users.
